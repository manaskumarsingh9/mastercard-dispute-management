Because your Spring Boot backend and your Replit frontend will be running on different "origins" (different URLs/ports), the browser will block the frontend from talking to the backend by default.

## 2. The "Gotcha": The CORS Configuration
Before you even touch the frontend, you **must** tell Spring Boot to allow the Replit frontend to talk to it. If you don't do this, your "Vibe" will be "Error 403" all night.

**Add this to your Spring Boot project immediately:**
Create a new configuration class (or add this to your main application class):

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("*") // In production, use your Replit URL
                .allowedMethods("GET", "POST", "PUT", "DELETE");
    }
}
```

## 3. The UI Strategy: Ant Design vs. Tailwind/shadcn
The other LLM suggested **Ant Design (antd)**. 
* **The Pro:** Ant Design is *fantastic* for "Case Management" because it has the best pre-built Tables and "Status Tags" (e.g., a "Pending" tag that is automatically orange).
* **The Con:** It can be a bit heavy. 
* **My Advice:** If you want a "Pro Enterprise" look with zero effort, go with **Ant Design**. If you want a "Modern Startup" look, go with **Tailwind + shadcn/ui**. Since you are under a 24-hour deadline, **Ant Design** is actually faster because you don't have to "build" the components; you just import them.
