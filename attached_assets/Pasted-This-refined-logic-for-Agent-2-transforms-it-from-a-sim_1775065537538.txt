### The Refined Case Detail & Enrichment Flow

1.  **Initial View (Instant):** The merchant clicks a claim row and sees the **Issuer Side data** and the **Agent 1 Summary**.
2.  **Enrichment Trigger (Merchant Action):** The merchant clicks "Enrich."
3.  **Agent 2 - Task 1 (Planning):** Gemini looks at the specific claim and "weird" details. It checks the standard template for that reason code but **adds dynamic requirements** (e.g., "Request warehouse packing video because customer claims the box was empty").
4.  **Evidence Engine (Execution):** The engine makes the API calls to PSPs and Delivery partners as instructed by Agent 2.
5.  **Agent 2 - Task 2 (Verification & Annotation):** Gemini reviews the API responses. It creates an **Annotated Evidence Map** (e.g., "✅ Signature obtained; ❌ Packing video unavailable in API").
6.  **Manual Top-up (Optional):** The merchant sees the "❌" flags. If they have that video or a manual email from the courier, they **upload it manually**.
7.  **Agent 4 - Recommendation (Configurable):** If enabled, Agent 4 reviews the *final* map (Auto + Manual) and suggests whether to challenge.
8.  **Agent 3b - Drafting:** If the merchant hits "Submit," Agent 3b writes the rebuttal using the verified evidence.
